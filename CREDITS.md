# Credits & Acknowledgments

The **Molavi Web Intelligence Engine (MWIE)** is an independent architecture designed and developed by **Taqi Molavi** (https://molavi.pro).

We gratefully acknowledge the architectural patterns, research benchmarks, and engineering innovations pioneered by the open-source community, specifically the following reference projects evaluated during the design of MWIE:

1. **Firecrawl** (Mendable AI) — Architectural inspiration for unified LLM web scraping and API contracts (`firecrawl/firecrawl`).
2. **Camoufox** (daijro) — Pioneer in browser fingerprint research and anti-detect engine integration (`daijro/camoufox`).
3. **Scrapling** (D4Vinci) — Inspiration for ultra-fast resilient HTML parsing and adaptive selector design (`D4Vinci/Scrapling`).
4. **Crawl4AI** (unclecode) — Pioneer in async Playwright crawling tailored for LLMs and RAG pipelines (`unclecode/crawl4ai`).
5. **ScrapeGraphAI** (ScrapeGraphAI team) — Architectural inspiration for graph-based extraction pipelines and prompt minimization (`ScrapeGraphAI/Scrapegraph-ai`).
6. **Apify MCP Server** (Apify) — Reference implementation for Model Context Protocol web tool exposure (`apify/apify-mcp-server`).
7. **Nanobrowser** (Nanobrowser team) — Innovation in browser-embedded agent state and multi-step web workflows (`nanobrowser/nanobrowser`).
8. **Agent Desktop** (Vercel Labs) — Insights into accessibility trees (AXTree) and semantic hierarchical representations (`vercel-labs/agent-desktop`).
9. **Maxun** (GetMaxun team) — Reference for web robot lifecycle, change detection, and monitoring pipelines (`getmaxun/maxun`).
10. **Crawlee** (Apify) — The gold standard for web crawling lifecycle management, request queue design, and autoscaling concurrency pools (`apify/crawlee`).

All reference trademarks, project names, and original copyrights belong to their respective creators. MWIE is implemented as an independent, clean-room open-source engine under the Apache License 2.0.
