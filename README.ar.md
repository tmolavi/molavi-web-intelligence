## ١. مقدمة عن المشروع

**محرك مولوي لذكاء الويب (Molavi Web Intelligence Engine - MWIE)** هو منصة مفتوحة المصدر، ذاتية الاستضافة (Self-Hosted)، مصممة خصيصاً لـ **تحسين محركات البحث التقني (Technical SEO)**، و**تحسين محركات البحث التوليدية (GEO - Generative Engine Optimization)**، و**فهرسة البحث بالذكاء الاصطناعي**، و**الوكلاء المستقلين (AI Agents)**.

لقد تحول البحث الحديث جذرياً من مطابقة الكلمات المفتاحية التقليدية إلى محركات الإجابة التوليدية المستندة إلى النماذج اللغوية الكبيرة (مثل Perplexity وChatGPT Search وGoogle Gemini Grounding). تقتصر أدوات كشط الويب التقليدية على جلب شفرات HTML الخام دون إدراك شبكة الكيانات (Entities)، أو الاستشهادات المرجعية (Citations)، أو سلامة سيو الموقع التقني.

يجمع MWIE بين الزحف السريع عبر HTTP، وتشغيل الجافاسكريبت بدون واجهة (Headless Playwright)، والتنقية الهيكلية لكود DOM، وتقييم السيو التقني، وقياس الجاهزية للذكاء الاصطناعي في إطار معماري موحد يمكن الوصول إليه عبر **REST API** وبروتوكول سياق النماذج **MCP (Model Context Protocol)**.

## ٢. الميزات الأساسية

- **بنية استخراج متعددة المحولات:**
  - *محول HTTP غير المتزامن السريع:* استخراج فائق السرعة في أقل من ٢٠ مللي ثانية دون استهلاك ذاكرة المتصفح.
  - *محول المتصفح Playwright:* تشغيل صفحات الجافاسكريبت الديناميكية والتطبيقات أحادية الصفحة (SPAs).
  - *محول Firecrawl المستقل:* اتصال منفصل تماماً بالخوادم السحابية أو المحلية دون أي تداخل في التراخيص.
- **موجه ذكي قائم على الأدلة (Intelligent Router):**
  - اختيار المحول الأمثل تلقائياً وفقاً لطبيعة الصفحة واحتياجات تشغيل الجافاسكريبت وتاريخ الاستقرار.
  - آلية رجوع تلقائي (Fallback) فورية في حال حدوث أي خطأ في الشبكة أو التقديم.
- **توليد محتوى نقي بصيغة Markdown:**
  - التخلص التلقائي من العناصر غير المفيدة (الرؤوس، التذييلات، قوائم التنقل، لافتات ملفات تعريف الارتباط).
  - إنتاج وثائق Markdown هرمية ومنسقة ومثالية لمدخلات النماذج التوليدية وأنظمة RAG.
- **خادم مدمج لبروتوكول سياق النماذج (MCP):**
  - توفير ١٢ أداة أصلية لوكلاء الذكاء الاصطناعي (مثل Hermes وHamzad وClaude Desktop وCursor).
- **كفاءة التكلفة والتشغيل الذاتي:**
  - مفتوح المصدر بنسبة ١٠٠٪، ولا يتطلب أي اشتراكات مدفوعة أو واجهات برمجية تجارية.

## ٣. قدرات السيو التقني (Technical SEO)

- **قابلية الفهرسة والتحكم بالزحف:** تدقيق علامات الميتا للروبوتات (`noindex` و`nofollow`)، وترويسات `X-Robots-Tag`، وأكواد استجابة HTTP.
- **تدقيق البيانات الوصفية:** مراجعة توافق طول عنوان الصفحة (`<title>`) والوصف (`meta description`) مع معايير محركات البحث.
- **مطابقة الرابط القانوني (Canonical URL):** التحقق من دقة رابط `rel="canonical"` ومطابقته للرابط المطلوب.
- **هيكل العناوين الرئيسية:** تحليل التدرج الهيكلي للعناوين من H1 إلى H6، والالتزام بوجود عنوان H1 رئيسي واحد.
- **إمكانية وصول الصور:** إحصاء الصور، والتحقق من نصوص البدائل (Alt text)، وتحديد الصور التي تفتقر إليها.
- **مخطط الروابط:** تصنيف الروابط الداخلية والخارجية وحسابها بدقة.
- **البيانات المهيكلة:** استخراج مخططات Schema.org من وسوم JSON-LD بالكامل.
- **بطاقات التواصل الاجتماعي:** التحقق من اكتمال وسوم Open Graph وTwitter Cards.
- **التدويل اللغوي:** فك تشفير وسوم `hreflang` والتحقق من كود اللغة المستهدف.
- **نسبة المحتوى إلى الكود:** حساب نسبة النص النقي مقارنة بالحجم الإجمالي لـ HTML كمؤشر على جودة الصفحة.
- **بطاقة درجات السيو الموزونة:** حساب درجة علمية من ٠ إلى ١٠٠ مصحوبة بتوصيات عملية للتحسين.

---

## ٤. قدرات تحسين محركات البحث التوليدية (GEO)

- **استخراج الكيانات والعلامات التجارية (Entity Intelligence):** استخراج كيانات العلامة التجارية، والمؤسسات، والأشخاص، والمنتجات من وسوم JSON-LD والنصوص.
- **ذكاء الاستشهاد والمصادر (Citation Intelligence):** رسم خرائط للروابط الخارجية، وعناصر الاقتباس (`blockquote`)، ونسب المصادر للمؤلفين.
- **استخراج كتل الأسئلة والأجوبة (Q&A Blocks):** الكشف التلقائي عن هياكل الأسئلة الشائعة والفقرات الاستفهامية.
- **التقطيع الدلالي (Semantic Chunking):** تقسيم المحتوى إلى أجزاء دقيقة ومقدرة التوكنات لقواعد البيانات المتجهة (Vector DBs).
- **مؤشر الجاهزية للذكاء الاصطناعي (AI-Readiness Score):** تقييم مدى قابلية استيعاب محركات البحث التوليدية (مثل Perplexity وChatGPT) للمحتوى من ٠ إلى ١٠٠.

## ٦. التثبيت والبدء السريع

### المتطلبات
- بايثون 3.10 أو أحدث
- لينكس، أو ماك، أو ويندوز

### التثبيت
```bash
git clone https://github.com/tmolavi/molavi-web-intelligence.git
cd molavi-web-intelligence
python3 -m pip install -e .
```

لتثبيت أدوات التطوير والاختبارات:
```bash
python3 -m pip install -e ".[dev]"
```

### مثال بلغة بايثون
```python
import asyncio
from mwie.crawler.engine import crawl_engine
from mwie.core.models import ExtractionOptions


async def main():
    options = ExtractionOptions(render_js=False, extract_seo=True, extract_geo=True)
    result = await crawl_engine.extract_single("https://molavi.pro", options)

    print(f"عنوان الصفحة: {result.seo.meta_title}")
    print(f"درجة السيو: {result.seo.seo_score}/100")
    print(f"درجة جاهزية الذكاء الاصطناعي: {result.geo.ai_readiness_score}/100")
    print(f"الكيانات المستخرجة: {[e.name for e in result.geo.entities]}")


asyncio.run(main())
```

## ٧. استخدام واجهة REST API

تشغيل الخادم:
```bash
uvicorn mwie.api.app:app --host 0.0.0.0 --port 8000
```
الوثائق التفاعلية متوفرة على: `http://localhost:8000/docs`

### طلب استخراج وتحليل صفحة
```bash
curl -X POST http://localhost:8000/api/v1/extract \
  -H "Content-Type: application/json" \
  -d '{"url": "https://molavi.pro"}'
```

### طلب مقارنة صفحات المنافسين
```bash
curl -X POST http://localhost:8000/api/v1/compare \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://molavi.pro", "https://example.com"]}'
```

## ٨. التكامل مع بروتوكول MCP للذكاء الاصطناعي

يوفر MWIE خادماً أصلياً لـ Model Context Protocol يشتمل على ١٢ أداة جاهزة:

| اسم الأداة | الغرض والوظيفة |
| :--- | :--- |
| `crawl_url` | استخراج وتدقيق شامل للسيو والـ GEO لرابط محدد |
| `crawl_domain` | زحف تكراري موسع عبر النطاق بالكامل |
| `extract_page_content` | استخراج سريع للنصوص النقية وصيغة Markdown |
| `analyze_seo` | تقرير السيو التقني وخطوات التحسين |
| `analyze_geo` | تحليل مؤشرات الاستشهاد والجاهزية لمحركات الذكاء الاصطناعي |
| `extract_entities` | استخراج كيانات العلامات التجارية والمؤسسات والمنتجات |
| `extract_structured_data` | فك وتوليد مخططات Schema.org JSON-LD |
| `analyze_sitemap` | كشف الروابط من خريطة الموقع (sitemap.xml) |
| `compare_pages` | مقارنة صفحات المنافسين جنباً إلى جنب |
| `batch_process_urls` | معالجة دفعات متزامنة من الروابط |
| `get_job_status` | فحص صحة المحرك وحالة الذاكرة المؤقتة |
| `get_extraction_metadata`| القياسات اللحظية لزمن الاستجابة ونسب النجاح للمحولات |

## ١٠. الأمان والحماية المتقدمة

- **حماية استباقية من SSRF:** حظر كامل لعناوين IP الخاصة وشبكات الاسترجاع المحلي (`127.0.0.1` و`10.0.0.0/8` و`192.168.0.0/16`).
- **الالتزام بملفات Robots.txt:** احترام شروط أصحاب المواقع وقواعد الوصول.
- **قوائم السماح والحظر:** إمكانية حصر عمليات الزحف على نطاقات محددة للأغراض المؤسسية.

## ١١. القياسات المعيارية وتدفق بيانات المجتمع التجريبي

نتائج تجريبية حقيقية تم قياسها على معالج لينكس ARM64 بعد ١٠٠ تكرار:
- **تحليل وتنقية كود HTML:** متوسط زمن الاستجابة ١٣.١٠ مللي ثانية (٧٦.٤ عملية/ثانية، ٤.٧ ميغابايت ذاكرة)
- **توليد الـ Markdown:** متوسط زمن الاستجابة ٢.٥٦ مللي ثانية (٣٩٠.٧ عملية/ثانية، ٢.٦ ميغابايت ذاكرة)
- **محرك السيو التقني:** متوسط زمن الاستجابة ١١.٢٥ مللي ثانية (٨٨.٩ عملية/ثانية، ٢.٤ ميغابايت ذاكرة)
- **محرك الكيانات والـ GEO:** متوسط زمن الاستجابة ٨.٥٦ مللي ثانية (١١٦.٨ عملية/ثانية، ٦.٤ ميغابايت ذاكرة)

### تدفق بيانات القياسات المجتمعية للمستودع
تتضمن أداة الويب المجانية على موقع `molavi.pro` خيار المشاركة التطوعية في القياسات المعيارية، حيث يتم تسجيل زمن الاستجابة وتقييمات الـ SEO والـ GEO بشكل مفتوح في الرابط [`https://molavi.pro/data/benchmark-records.json`](https://molavi.pro/data/benchmark-records.json) (دون حفظ أي بيانات حساسة). يمكنك مزامنة هذه البيانات محلياً عبر:

```bash
python3 scripts/sync_benchmarks.py
```

التقرير والمنهجية الكاملة في [docs/BENCHMARKS.md](docs/BENCHMARKS.md).
