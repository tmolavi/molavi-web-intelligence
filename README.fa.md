## ۱. معرفی پروژه

**موتور هوشمندی وب مولوی (Molavi Web Intelligence Engine - MWIE)** یک پلتفرم متن‌باز، خودمیزبان (Self-Hosted) و ماژولار است که به‌طور اختصاصی برای **سئوی تکنیکال (Technical SEO)**، **بهینه‌سازی برای موتورهای هوش مصنوعی (GEO - Generative Engine Optimization)**، **نمایه‌سازی جستجوی مبتنی بر هوش مصنوعی** و **عامل‌های هوشمند خودکار (AI Agents)** طراحی و پیاده‌سازی شده است.

دنیای جستجو از تطبیق کلمات کلیدی سنتی به‌سمت موتورهای پاسخ‌محور مبتنی بر مدل‌های بزرگ زبانی (مانند Perplexity، ChatGPT Search و Google Gemini Grounding) حرکت کرده است. ابزارهای استخراج سنتی تنها به دریافت کدهای خام HTML می‌پردازند و از درک ساختار موجودیت‌ها (Entities)، استنادات (Citations) و سلامت سئوی تکنیکال عاجزند.

سامانه MWIE با ترکیب خزش پرسرعت HTTP، رندرینگ جاوااسکریپت بدون سر (Headless Playwright)، پالایش ساختاریافته DOM، ارزیابی سئوی تکنیکال و سنجش آمادگی هوش مصنوعی، بستری جامع را از طریق **REST API** و پروتکل استاندارد **MCP (Model Context Protocol)** فراهم می‌سازد.

## ۲. ویژگی‌های کلیدی

- **موتور استخراج چندآداپتوره یکپارچه:**
  - *آداپتور پرسرعت Native HTTP:* استخراج با تاخیر زیر ۲۰ میلی‌ثانیه بدون مصرف حافظه مرورگر.
  - *آداپتور مرورگر Playwright:* رندرینگ کامل برنامه‌های تک‌صفحه‌ای جاوااسکریپت (SPAs).
  - *آداپتور مستقل Firecrawl:* اتصال decoupled به خوشه‌های خارجی یا محلی بدون وابستگی کپی‌لفت.
- **مسیریاب هوشمند و یادگیرنده (Intelligent Router):**
  - انتخاب خودکار بهترین آداپتور بر اساس پیچیدگی صفحه، نیاز به JS و تاریخچه پایداری.
  - سازوکار بازگشت خودکار (Fallback) در صورت بروز خطا.
- **تولید محتوای پالایش‌شده و Markdown استاندارد:**
  - حذف هوشمند کدهای مزاحم (هدر، فوتر، منوهای ناوبری و بنرهای کوکی).
  - تبدیل DOM تمیز به ساختار Markdown سلسله‌مراتبی بهینه‌شده برای LLM و RAG.
- **پشتیبانی بومی از سرور MCP (Model Context Protocol):**
  - ارائه ۱۲ ابزار بومی برای عامل‌های هوشمند (مانند هرمس، همزاد، Claude Desktop و Cursor).
- **بهینگی هزینه و استقلال کامل:**
  - ۱۰۰٪ متن‌باز و بدون نیاز به کلیدهای API تجاری یا پرداخت دلاری.

## ۳. قابلیت‌های سئوی بومی (Technical SEO)

- **ایندکس‌پذیری و کنترل خزش:** بررسی تگ‌های متای ربات‌ها (`noindex`, `nofollow`)، هدرهای `X-Robots-Tag` و کدهای وضعیت HTTP.
- **ممیزی متادیتا:** تحلیل طول و تناسب عناوین صفحه (`<title>`) و توضیحات متا (`meta description`).
- **اعتبارسنجی تگ Canonical:** تطابق آدرس کانونیکال با آدرس واقعی درخواست.
- **سلسله‌مراتب تیترها:** تحلیل ساختاری تگ‌های H1 تا H6 و الزام به وجود تنها یک H1 اصلی.
- **دسترس‌پذیری تصاویر:** شمارش تصاویر، بررسی متن جایگزین (Alt) و گزارش تصاویر فاقد Alt.
- **گراف پیوندها:** تفکیک و شمارش لینک‌های داخلی (Internal) و خارجی (External).
- **داده‌های ساختاریافته:** استخراج کامل داده‌های Schema.org از اسکریپت‌های JSON-LD.
- **کارت‌های اجتماعی:** اعتبارسنجی تگ‌های Open Graph و Twitter Cards.
- **سیگنال‌های چندزبانه:** پارس تگ‌های `hreflang` و کدهای زبان.
- **نسبت متن به کد HTML:** محاسبه نسبت محتوای تمیز به کل حجم کد به عنوان شاخص کیفیت.
- **کارنامه وزنی سئو:** تولید امتیاز شفاف بین ۰ تا ۱۰۰ همراه با توصیه‌های عملی رفع نقص.

---

## ۴. قابلیت‌های سئوی هوش مصنوعی (GEO Native)

- **شناسایی موجودیت‌های برند (Entity Recognition):** استخراج برند، سازمان، اشخاص و محصولات از متون و کدهای JSON-LD.
- **هوشمندی استناد و منابع (Citation Intelligence):** شناسایی ارجاعات بیرونی، تگ‌های نقل‌قول (`blockquote`) و انتساب نویسنده.
- **استخراج بلوک‌های دانش پرسش و پاسخ (Q&A Blocks):** کشف خودکار ساختارهای FAQPage و پرسش‌های متنی.
- **قطعه‌بندی معنایی (Semantic Chunking):** خرد کردن هوشمند متون بر اساس توکن‌ها و طول نویسه‌ها برای پایگاه‌های برداری RAG.
- **امتیاز آمادگی هوش مصنوعی (AI-Readiness Score):** سنجش میزان استنادپذیری و شفافیت ساختار متن برای موتورهای مولد (Perplexity، ChatGPT و غیره).

## ۶. نصب و راه‌اندازی سریع

### پیش‌نیازها
- پایتون نسخه 3.10 یا بالاتر
- لینوکس، مک یا ویندوز

### نصب پروژه
```bash
git clone https://github.com/tmolavi/molavi-web-intelligence.git
cd molavi-web-intelligence
python3 -m pip install -e .
```

برای توسعه و اجرای تست‌ها:
```bash
python3 -m pip install -e ".[dev]"
```

### نمونه کد پایتون
```python
import asyncio
from mwie.crawler.engine import crawl_engine
from mwie.core.models import ExtractionOptions


async def main():
    options = ExtractionOptions(render_js=False, extract_seo=True, extract_geo=True)
    result = await crawl_engine.extract_single("https://molavi.pro", options)

    print(f"عنوان صفحه: {result.seo.meta_title}")
    print(f"امتیاز سئو: {result.seo.seo_score}/100")
    print(f"امتیاز آمادگی هوش مصنوعی: {result.geo.ai_readiness_score}/100")
    print(f"موجودیت‌های شناسایی‌شده: {[e.name for e in result.geo.entities]}")


asyncio.run(main())
```

## ۷. استفاده از سرویس REST API

اجرای وب‌سرور:
```bash
uvicorn mwie.api.app:app --host 0.0.0.0 --port 8000
```
مستندات تعاملی Swagger در آدرس زیر در دسترس است: `http://localhost:8000/docs`

### فراخوانی نمونه: استخراج و تحلیل صفحه
```bash
curl -X POST http://localhost:8000/api/v1/extract \
  -H "Content-Type: application/json" \
  -d '{"url": "https://molavi.pro"}'
```

### فراخوانی نمونه: مقایسه صفحات رقبا
```bash
curl -X POST http://localhost:8000/api/v1/compare \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://molavi.pro", "https://example.com"]}'
```

## ۸. یکپارچه‌سازی با پروتکل هوش مصنوعی (MCP)

موتور MWIE دارای سرور بومی پروتکل Model Context Protocol با ۱۲ ابزار کاربردی است:

| نام ابزار | کارکرد |
| :--- | :--- |
| `crawl_url` | استخراج و ممیزی جامع سئو و GEO برای یک صفحه |
| `crawl_domain` | خزش بازگشتی و عمیق چندصفحه‌ای در دامنه |
| `extract_page_content` | استخراج پرسرعت متن پالایش‌شده و کد Markdown |
| `analyze_seo` | گزارش جامع سئوی تکنیکال و توصیه‌های رفع نقص |
| `analyze_geo` | تحلیل شاخص‌های بهینه‌سازی برای هوش مصنوعی (GEO) |
| `extract_entities` | استخراج موجودیت‌های برند، سازمان، اشخاص و کالا |
| `extract_structured_data` | استخراج اسکیماهای داده‌ای JSON-LD |
| `analyze_sitemap` | کشف و خواندن آدرس‌ها از نقشه سایت (sitemap.xml) |
| `compare_pages` | مقایسه همزمان و چندصفحه‌ای رقبا |
| `batch_process_urls` | پردازش دسته‌ای و همزمان فهرستی از صفحات |
| `get_job_status` | وضعیت سلامت موتور و حافظه کش |
| `get_extraction_metadata`| آمار تاخیر و پایداری زنده آداپتورهای استخراج |

## ۱۰. امنیت و خزش مسئولانه

- **مسدودسازی SSRF:** تمام رنج‌های خصوصی IP (شامل `127.0.0.1`، `10.0.0.0/8`، `192.168.0.0/16` و شبکه‌های محلی) مسدود هستند.
- **رعایت قوانین Robots.txt:** احترام به محدودیت‌های مشخص‌شده توسط مدیران سایت‌ها.
- **فهرست مجاز و ممنوع دامنه‌ها:** قابلیت اعمال محدودیت خزش بر دامنه‌های مجاز سازمانی.
